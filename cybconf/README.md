# IEEE CYB Conf 2027 Website

Official website for the **IEEE International Conference on Cybernetics 2027 (IEEE CYB Conf 2027)**, hosted at the University of Calabria in Rende (Cosenza), Calabria, Italy.

**Theme:** *"Towards Smart Humanoid Robotics"*

**Location:** Rende (Cosenza), Calabria, Italy  
**Venue:** Conference Center, University of Calabria  
**Dates:** 10-13 May 2027

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Conference dates and key info are in `_data/cyb_data.json`, the committee in `_data/committee.yml`,
CFP topics in `_data/cfp_topics.yml`, touristic info/cuisine in `_data/calabria.yml`, and the menu in `_data/navigation.yml`.
